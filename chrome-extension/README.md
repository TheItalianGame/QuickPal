# QuickPal Chrome Tabs Extension

This unpacked Chrome extension sends open tab titles and URLs to QuickPal through Chrome Native Messaging. It does not use a debug port.

## Install

1. Build and run QuickPal once so it registers the native host.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select this `chrome-extension` folder.

QuickPal should then show tab results from `tab`, `tabs`, `chrome`, or the Browser tabs provider shortcut.
